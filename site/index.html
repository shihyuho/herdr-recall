How it works

Most recent first. Typing narrows, never reshuffles.

One key lists every space, tab, pane and agent you've been in, most recently focused first, and opens on the one you were in just before this one. Each row shows where it lives, its folder, its branch, and whether an agent there needs you.

Back in two keys

⌘E opens on the place you were in just before this one, so ⏎ takes you back, across spaces.

Agents that need you stand out

Rows you've never been to follow the ones you have, those that need you first. In Agents, ⌃S switches to Priority: by status, latest change first.

Fuzzy search, fzf syntax

Rows where every term appears unbroken come first; the rest follow. Both groups keep the list's own order, so rows don't trade places as you type.

Find a pane by what it's doing

Clues finds a pane by the command it runs, the host it's ssh'd into, the file it has open, the text it printed, or the port it listens on. Recall runs git, ps and lsof on your machine; nothing leaves it.

Search syntax

The fzf you already type.

Queries follow fzf's extended-search mode, in every list. Every term must match, each in any one field of a row: its name, where it lives, its folder, its branch. A lowercase term ignores case; one with an uppercase letter matches it exactly.

Install

Install once. Press the key once.

Recall needs the Herdr app, with herdr-app on your PATH. After installing, press your open key once: that starts Recall's tracker, which records every focus change from then on and comes back each time Herdr starts.

Two ways in

pick one
With your agent

Ask your agent in Herdr. It copies mods/recall/ into place, adds the ⌘E key (asking first if you already use it), and runs herdr-app check.

Add the Herdr mod at github.com/shihyuho/herdr-recall
With the script

Needs rsync. Then bind a key, below.

git clone https://github.com/shihyuho/herdr-recall.gitcd herdr-recall./install.sh
Bind a key · ~/.config/herdr-app/keys.json
{  "global": {    "cmd-e": "mod.open:recall"  }}

cmd-e is ⌘E on macOS; elsewhere, pick a key you don't use yet.
